## What We Learned

### Tech Stack
- React SPA (pre-compiled Vite bundles, no source in repo) + Three.js 3D canvas
- Express backend deployed as a single Vercel serverless function (`api/index.js`)
- Supabase (PostgreSQL) as the cloud database with an in-memory fallback seed store
- JWT authentication (HS256), no OAuth providers

### Architecture
- **Hybrid static SPA + serverless API** on Vercel
- Single-file API monolith (1393 lines) handling all routes
- Dual-engine pattern: Supabase when configured, `memoryStore` (ephemeral!) otherwise
- 3D atmosphere via Three.js + custom ESBD canvas layers

### Key Risks Found
| Severity | Item |
|---|---|
| 🔴 Critical | Hardcoded plaintext admin/demo passwords in source |
| 🔴 Critical | Predictable fallback JWT secret (`'esports-bangladesh-production-jwt-2026'`) |
| 🔴 Critical | CORS wildcard on all API routes |
| 🟠 High | In-memory state lost on every Vercel cold start |
| 🟠 High | No frontend source project — bundle-only repo |
| 🟠 High | API monolith — 1393 lines, no router splitting |
